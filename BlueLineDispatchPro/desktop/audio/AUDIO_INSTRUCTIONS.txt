================================================================================
  BlueLineDispatchPro — Dispatcher Audio File Instructions
================================================================================

FOLDER STRUCTURE
----------------
Each category folder holds WAV audio files named sequentially:
  01.wav, 02.wav, 03.wav ... (up to as many as you want)

The app picks one file at random from the matching category folder.

CATEGORY FOLDERS:
  acknowledgment/   → General "10-4", "copy that", "received" responses
  backup/           → Backup request acknowledgments
  callout/          → New call dispatched responses
  chase/            → Vehicle/foot pursuit responses
  general/          → Background chatter, bulletins, general traffic
  panic/            → Officer emergency / panic button responses
  plate/            → Plate/ALPR query responses
  scene/            → On-scene arrival acknowledgments
  scanner/          → Background scanner chatter (scanner mode)

================================================================================
  RECOMMENDED AUDIO SPECS
================================================================================
  Format:    WAV (PCM 16-bit, mono)
  Sample Rate: 44100 Hz (or 22050 Hz)
  Duration:  1–8 seconds per file
  Volume:    Normalize to -6 dB before adding radio effects

The app applies radio processing automatically:
  - Bandpass filter (300–3400 Hz, radio voice range)
  - Subtle noise/static overlay
  - Soft distortion for warmth
  - Optional squelch click at start

You can set Radio Effect Intensity to 0 in Settings to play raw audio.

================================================================================
  OPTION 1: RECORD YOUR OWN
================================================================================
Equipment needed:
  - Microphone (USB condenser or even built-in)
  - Audacity (free: https://www.audacityteam.org/)
  - Optional: EQ preset for "radio voice" sound

Recording steps:
  1. Open Audacity → select your microphone input
  2. Record yourself (or someone with a professional voice) reading scripts
  3. Apply EQ: cut everything below 200Hz and above 4000Hz
  4. Normalize to -6 dB
  5. Export as WAV → save to the correct category folder

Sample scripts to record (acknowledgment/):
  - "10-4, copy that."
  - "Dispatch copies. All units copy."
  - "Received. 10-4."
  - "Copy, understood."
  - "10-4, go ahead."
  - "Dispatch, copy that."

Sample scripts (backup/):
  - "Copy, units en route to your location."
  - "All available units, backup requested at your location. Please respond."
  - "10-4, backup is on its way. ETA two minutes."
  - "Dispatch to all units — backup requested. Please respond immediately."

Sample scripts (callout/):
  - "All units, we have a [call type] at [location]. Please respond."
  - "10-4, dispatching units to your location now."
  - "Copy that. Units are being dispatched."

Sample scripts (plate/):
  - "Copy, running that plate now. Stand by."
  - "10-4. Checking registration. Stand by one."
  - "Dispatch copies. ALPR query submitted."

Sample scripts (chase/):
  - "Copy, all units be advised — vehicle pursuit is active."
  - "10-4. Air support has been notified. All units stand by."
  - "Copy pursuit. All available units, please respond."
  - "All units, pursuit is authorized. Spike strips are being requested."

Sample scripts (panic/):
  - "ALL UNITS — OFFICER NEEDS ASSISTANCE. All available units respond IMMEDIATELY."
  - "10-99, officer down! All units respond! All units respond!"
  - "EMERGENCY — All units respond to officer assistance call. Code 3!"

Sample scripts (scene/):
  - "10-4, copy you are on scene."
  - "Copy that. You are noted on scene."
  - "Received. Backup en route."

Sample scripts (scanner/):
  - "Unit 2-Lincoln-15, traffic stop on Strawberry Ave."
  - "All units, be advised — road closure on Del Perro Freeway."
  - "2-Adam-23, 10-8 and available."
  - "Dispatch to all units: 10-4 on that. Units are clear."
  - "14-King-7, I'm 10-6 on a traffic stop at Vinewood."
  - "Control to all units — we have a [code] at [location]. Nearest unit respond."

================================================================================
  OPTION 2: AI-GENERATED VOICE (Recommended for 1000+ files)
================================================================================
  Use ElevenLabs (https://elevenlabs.io) or similar for high-quality voices.

  Recommended ElevenLabs settings:
    - Voice: "Rachel" or similar professional female voice
    - Stability: 0.45
    - Clarity: 0.75
    - Style Exaggeration: 0.10

  After generating:
    1. Download as MP3 or WAV
    2. Optionally apply Audacity radio EQ (or let the app do it)
    3. Name files: 01.wav, 02.wav, etc.
    4. Drop into the correct category folder

  FREE TTS alternatives:
    - TTS Monster (https://ttsmonster.com)
    - Murf AI (https://murf.ai)
    - Google Cloud TTS (https://cloud.google.com/text-to-speech)

================================================================================
  APPLYING MANUAL RADIO EFFECTS IN AUDACITY
================================================================================
  1. Open WAV in Audacity
  2. Effect → Equalization → Graphic EQ:
       - Cut all below 250 Hz to -∞
       - Cut all above 3500 Hz to -∞
       - Slight boost at 1kHz (+3dB)
  3. Effect → Distortion → Soft Clipping (Amount: 10)
  4. Generate → Noise → White noise at -30 dB (mix into track at 15%)
  5. Effect → Normalize → -3 dB
  6. File → Export → WAV (16-bit PCM, 44100 Hz, Mono)

  Alternatively, use the Audacity "Radio" preset if available in your version.
